# Step-by-step update guide

Use this guide only after the package has been checked locally.

## Step 1

Download and inspect the prepared package. Do not update GitHub or Zenodo yet.

## Step 2

Upload/update files in GitHub repository.

## Step 3

Create a GitHub release v1.1.0.

## Step 4

Create a Zenodo New Version from record 21179510.

## Step 5

After Zenodo generates the new DOI, update README.md, CITATION.cff, manuscript PDF/LaTeX, and GitHub release notes.

## Step 6

Only then use the final PDF for journal submission.
